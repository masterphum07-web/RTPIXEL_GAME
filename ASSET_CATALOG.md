## Regeneration

Source drawing scripts are in `scripts/`. They use the installed Astra Pixel Art skill runtime and write editable exports beneath `pixelart/exports/`; copy the matching runtime PNG to `public/assets/` after regenerating. `src/game/hospital-scene.ts` loads the 192×288-per-cell character atlas for the Player and all current NPCs. Player clothes and all role rows preserve the previous on-screen frame and effective Arcade body. `src/game/room-scene.ts` loads the room layers, eight-frame actor sheet and PixelFX acquisition atlas. `src/game/dungeon-scene.ts` loads the PixelFX hit-spark atlas. The production game loads only assets from `public/assets/`.

No paid assets, remote images, API keys, or assets from Ragnarok Online are used by this cycle.
